# DSA (Python)

A growing collection of data-structures & algorithms in Python.

## Structure

- `arrays/`
- `strings/`
- `stack/`
- `linked_list/`
- `sorting/`
- `heap/`
- `dp/`
- `graphs/`

Each solution file contains:
- A short problem statement
- The core approach
- Time/space complexity
- A small `__main__` sanity check

## Running tests locally

```bash
python -m pip install -r requirements-dev.txt
pytest -q
```

## Contributing

Keep solutions:
- clear (type hints + docstring)
- small (focus on one problem per file)
- deterministic (no input prompts)
